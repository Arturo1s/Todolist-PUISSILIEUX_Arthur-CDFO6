# Todo List Application

## Description
A simple console-based Todo List application designed to help users manage their tasks effectively. Users can add, delete, and mark tasks as completed using an interactive menu in the terminal.

## Features
- **View Tasks:** Display all tasks with their completion status.
- **Add Task:** Add a new task to the list.
- **Delete Task:** Remove an existing task from the list.
- **Mark Task as Completed:** Mark any task as completed.

## Prerequisites
- Python 3.x installed on your machine.
